# GlanceVeil Obsidian Community listing

## Long description

GlanceVeil adds a casual visual-privacy layer to your notes without changing
their Markdown source. It renders eligible Latin text in the editor and Reading
view through familiar alternate glyph systems, making notes slower for someone
nearby to read at a glance while keeping them usable for you.

Choose from Greek-looking, Cyrillic, Hebrew-glyph, Arabic-glyph, Katakana,
Hiragana, and experimental Gregg Simplified-style rendering. Adjust the reading
profile, renderer, glyph scale, letter spacing, and the percentage of words that
remain visible. Use the ribbon or commands to toggle the veil, cycle scripts,
or temporarily reveal selected text. A desktop status-bar control provides an
additional quick toggle, while the ribbon works on both desktop and mobile.

GlanceVeil works locally and offline. It has no account, telemetry, advertising,
or runtime network service, and it does not write transformed text into vault
files. It covers Markdown editor and Reading views; file names, search results,
backlinks, properties, Canvas, and interfaces created by other plugins remain
outside its current scope.

GlanceVeil provides visual obscurity, not encryption. Anyone with access to the
vault, copied text, accessibility tools, or the underlying files can still read
the original content.

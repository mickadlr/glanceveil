Where should GlanceVeil start active?

Default veil

Site and tab rules override these choices.

Visible words are readable to anyone looking at the page. Common sensitive-looking tokens remain fully veiled.

Adaptive behavior

These features add convenience and visual variation. They do not increase the security boundary.

Input veiling occurs visually after a space in text fields and supported chat editors. The active word and real submitted value remain unchanged; password fields are always excluded.

Sensitive-looking detection is local and best-effort. It can miss private text and should never be treated as redaction.

Saved sites

Per-site on/off and appearance rules remain on this device.

Custom declarative pack

Custom packs are inert JSON data. They cannot contain code or remote assets.


      

    


    

      
Privacy boundary

      
    
        
  • No page text, browsing history, or usage telemetry is stored.
    • 
        
  • Overlay mode keeps source text available to pages, copying, search, accessibility tools, and inspection.
    • 
        
  • Unicode mode temporarily changes visible DOM text and restores captured page text when disabled.
    • 
        
  • Optional input mirrors never alter submitted values and never apply to password fields.
    • 
        
  • Images, video, canvas, PDFs, browser chrome, and determined inspection remain readable.
